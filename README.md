# Meteo Grid Statistics · 气象格点分区统计

在 QGIS「栅格」菜单启动。读取 NetCDF、GRIB、GeoTIFF，选择变量/子数据集、时间波段、面文件及其中图层，设置统计量和合理范围，选择新输出文件，点击「开始统计」。后台计算可取消，结果写入 GeoJSON、Shapefile 或 CSV，空间输出为 EPSG:4326；GeoJSON/Shapefile 自动添加到地图。

支持 JSON/GeoJSON、SHP、KML 及 OGR 面图层。每个源要素的每个所选波段独立生成一行；src_fid 保留源 ID，zone_id 为所选标识字段。dims 保存时间、层次等元数据，time 尽可能解码为 UTC；非公历原样保留值、单位和日历并提醒。无时间元数据时 time 留空，band 保持可识别。

统计指标：计数、最小、最大、平均、中位、总和、总体标准差、总体方差、极差。不按面积加权。默认像元中心落面即纳入，可勾选所有接触像元；重叠面独立统计，孔洞不纳入。先将面转换到格点原坐标系进行计算，输出面再转换为 EPSG:4326，格点不重采样。

NoData 和掩膜排除；应用 scale/offset 后计算。NaN、Inf 始终排除并提醒（若作为 NoData 定义则计入缺测）。物理异常无法跨变量统一推断，请设置解码后单位的合理上下限。范围外异常默认排除，也可保留。n_valid 是实际参与统计数，n_nodata 是缺测数，n_bad 是异常数；保留范围外值时 n_bad 与 n_valid 可重叠。无有效像元时 count=0，其余统计量为空，绝不填零伪造观测。

完整提醒写入同名 `.warnings.json`，包含源 FID、波段和原因；窗口显示最多 500 条提醒和 500 行结果，导出数据完整。CSV 使用 UTF-8 BOM，含 WKT 几何；Shapefile 使用 UTF-8 和短字段名，超长字符串拒绝导出而非静默截断。CSV 字符串按原值导出，若用表格软件打开来自不可信数据的属性，应按文本导入。

0.1.1：NetCDF 缺少空间定位时，可从对应维度的一维 lat/lon、latitude/longitude 坐标恢复定位。验证有限值、严格单调和等间隔（容忍 float32 舍入误差），按像元中心向外扩半格，保留升序/降序行列方向。缺少 CRS 时推定 WGS84；界面「定位说明」和导出 `.warnings.json` 明确记录 GEOLOCATION_RECOVERED、CRS_ASSUMED_WGS84。恢复在内存中完成，不修改原始文件。点击添加格点到地图时生成临时 GeoTIFF；持久保存地图项目时请将该栅格另存。

限制：依赖 QGIS 附带 GDAL/OGR、NumPy（恢复功能使用 GDAL 多维 API）；驱动支持取决于 QGIS 安装。仅支持规则格点，不直接支持曲线网格、网格拓扑或非等间隔坐标。恢复定位要求经纬度为数据最后两个维度；不能识别坐标或缺失 CRS 的其他格式需先正确赋予定位并另存。跨日期变更线或跨 0/360 接缝的面需先分割。全球 0–360 格点支持不跨接缝的负经度面。精确中位数每面最多 500 万有效像元，其他统计采用 512×512 分块累计。提醒数量随面和波段数量增加，建议非常大的批任务分批处理。

QGIS 3.22–3.99 为目标范围，实测环境见项目测试报告；尚未验证 QGIS 4。GPL-3.0-or-later，许可全文见 LICENSE。
